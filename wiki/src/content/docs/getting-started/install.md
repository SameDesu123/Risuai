RisuAI는 설치 없이 웹에서 바로 쓸 수도 있고, 데스크톱 앱이나 직접 띄운 서버로 쓸 수도 있습니다. 어느 쪽이든 기능은 거의 같고, **데이터가 어디에 저장되는지**가 가장 큰 차이입니다.

| 방법 | 이럴 때 좋습니다 | 데이터가 저장되는 곳 |
| --- | --- | --- |
| [웹](#웹에서-바로-쓰기) | 일단 써 보고 싶을 때 | 브라우저 저장소 |
| [데스크톱 앱](#데스크톱-앱) | PC 한 대에서 꾸준히 쓸 때 | 내 컴퓨터 |
| [Docker](#docker로-직접-호스팅하기) | 서버나 NAS에 올려 두고 여러 기기에서 접속할 때 | 서버의 Docker 볼륨 |
| [직접 빌드](#소스에서-직접-빌드하기) | 코드를 고치거나 Docker를 쓸 수 없을 때 | 서버 |

어떤 방법을 고르든 [백업](#데이터-백업하기)은 꼭 해 두세요.

## 웹에서 바로 쓰기

[risuai.net](https://risuai.net)에 접속하면 바로 쓸 수 있습니다. RisuAI 공식 README에서도 가장 먼저 권하는 방법입니다.

:::caution[브라우저 데이터를 지우면 함께 사라질 수 있습니다]
웹 버전의 데이터는 브라우저 안에 저장됩니다. 브라우저의 사이트 데이터나 캐시를 지우거나, 시크릿 창에서 쓰거나, 다른 브라우저로 옮기면 캐릭터와 채팅이 보이지 않을 수 있습니다. 주기적으로 [로컬 백업](#데이터-백업하기)을 받아 두세요.
:::

## 데스크톱 앱

[GitHub 릴리스 페이지](https://github.com/kwaroran/RisuAI/releases)에서 최신 버전의 설치 파일을 받습니다. 릴리스는 다음 환경용으로 빌드됩니다.

- **Windows** (x64): 설치 프로그램
- **macOS**: Apple Silicon(M1 이상)용과 Intel용이 따로 있습니다.
- **Linux** (x64): `.deb`, `.rpm`, `.AppImage`

데스크톱 앱은 데이터를 내 컴퓨터에 저장하므로 브라우저 데이터를 지워도 영향을 받지 않습니다.

## Docker로 직접 호스팅하기

서버, NAS, 홈 서버 등에 RisuAI를 띄워 두고 휴대폰이나 다른 PC에서 접속하고 싶을 때 쓰는 방법입니다. Docker와 Docker Compose가 설치되어 있어야 합니다.

```sh
curl -L https://raw.githubusercontent.com/kwaroran/Risuai/refs/heads/main/docker-compose.yml | docker compose -f - up -d
```

실행한 뒤 브라우저에서 `http://localhost:6001`(다른 기기라면 `http://서버주소:6001`)로 접속합니다.

- 이미지는 `ghcr.io/kwaroran/risuai:latest`이며, `amd64`와 `arm64`용이 함께 올라와 있습니다.
- 데이터는 `risuai-save`라는 Docker 볼륨(컨테이너 안의 `/app/save`)에 저장되므로, 컨테이너를 지우고 다시 만들어도 남아 있습니다.
- 새 버전으로 올리려면 `docker pull ghcr.io/kwaroran/risuai:latest`로 이미지를 받은 뒤 위 명령을 다시 실행합니다.

:::caution[인터넷에 공개할 때]
6001번 포트를 인터넷에 그대로 열기보다는 HTTPS를 붙인 리버스 프록시(Nginx, Caddy, Cloudflare Tunnel 등) 뒤에 두는 것을 권합니다. 리버스 프록시 뒤에서 실제 접속자 IP를 받아야 한다면 `TRUST_PROXY` 환경 변수를 설정합니다. 이 값은 신뢰할 수 있는 프록시 뒤에서만 켜야 합니다.
:::

## 소스에서 직접 빌드하기

Docker 없이 Node.js로 서버를 띄우는 방법입니다. Node.js 22.13 이상과 Git이 필요합니다.

```sh
git clone https://github.com/kwaroran/RisuAI.git
cd RisuAI
sh server.sh
```

`server.sh`는 pnpm을 설치하고, 의존성을 받은 뒤 웹 프런트엔드를 빌드하고, Node 서버를 실행합니다. 기본 포트는 6001이며 `PORT` 환경 변수로 바꿀 수 있습니다.

알아 둘 점:

- `VITE_RISU_LEGAL_CONFIGURED`를 설정하지 않고 빌드하면 접속할 때 법적 고지 경고 화면이 나옵니다. `server.sh` 안의 주석에 따르면 이 값은 **혼자 쓰는 개인 서버**, 원본에 기여하기 위한 개발·테스트용 포크, 또는 이용약관과 개인정보처리방침을 제대로 갖춘 포크에서만 `TRUE`로 설정해야 합니다.
- RisuAI 저장소의 Node 서버 문서에는 이 서버가 앞으로 [Hono](https://hono.dev/) 기반 서버로 대체될 수 있다는 안내가 있습니다.

## 데이터 백업하기

RisuAI 안에서 **설정 → 계정 & 파일**로 들어가면 백업 메뉴가 있습니다.

- **로컬 백업 저장**: 캐릭터, 채팅, 설정, 에셋을 모두 담은 백업 파일을 내려받습니다.
- **부분 로컬 백업 저장 (캐릭터 에셋 제외)**: 캐릭터 에셋을 빼서 더 가벼운 백업을 만듭니다.
- **로컬 백업 불러오기**: 백업 파일로 데이터를 되돌립니다.

다른 기기나 다른 설치 방법으로 옮길 때도 이 백업 파일을 쓰면 됩니다. 예를 들어 웹 버전에서 백업을 받은 뒤, 데스크톱 앱에서 불러오면 그대로 옮겨집니다.
