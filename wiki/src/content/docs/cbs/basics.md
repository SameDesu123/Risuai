CBS(Curly Braced Syntax)는 `{{char}}`처럼 이중 중괄호로 감싼 RisuAI의 템플릿 문법입니다. 캐릭터 설명, 프롬프트, 로어북, 정규식 스크립트, 채팅 메시지 등 RisuAI 곳곳에 쓸 수 있고, 처리될 때 결괏값으로 바뀝니다.

이 페이지는 문법이 **실제로 어떻게 동작하는지**를 설명합니다. 개별 함수 목록은 [CBS 레퍼런스](/cbs/reference/)에 있습니다.

## 기본 모양

```text
{{이름}}
{{이름::인자1::인자2}}
```

함수 이름 뒤에 `::`로 인자를 이어 붙입니다. 예를 들어 `{{getvar::hp}}`는 `hp` 변수의 값으로, `{{randint::1::6}}`은 1부터 6 사이의 정수로 바뀝니다.

- **이름은 느슨하게 맞춥니다.** 대소문자를 가리지 않고 공백, `_`, `-`를 무시하므로 `{{Get_Var::hp}}`와 `{{getvar::hp}}`는 같습니다. 인자는 그대로 비교됩니다.
- **모르는 이름은 그대로 남습니다.** `{{없는함수::x}}`처럼 등록되지 않은 이름은 오류 없이 글자 그대로 출력됩니다. 결과에 중괄호가 그대로 보인다면 오타부터 의심하세요.
- **옛날식 `:` 한 개도 동작합니다.** 이름 바로 뒤의 콜론이 하나뿐이면 `:` 기준으로 나눕니다. `{{getvar:hp}}`도 동작하지만 인자 안에 `:`가 들어가면 엉뚱하게 잘리므로 새로 쓸 때는 `::`를 쓰세요.
- **`<user>`, `<char>`, `<bot>`은 CBS로 바뀝니다.** 대소문자와 상관없이 각각 `{{user}}`, `{{char}}`, `{{bot}}`으로 바꾼 뒤 처리합니다. HTML 태그처럼 보이지만 HTML이 아닙니다.

## 안쪽부터 계산됩니다

CBS는 중첩할 수 있고, **가장 안쪽 것부터** 계산됩니다. 바깥 함수는 안쪽이 이미 계산된 결과를 인자로 받습니다.

```text
{{upper::{{getvar::name}}}}
```

`{{getvar::name}}`이 먼저 값(예: `risu`)으로 바뀌고, 그다음 `{{upper::risu}}`가 계산되어 `RISU`가 됩니다.

## 계산식: `{{? }}`

```text
{{? 1+2}}                     → 3
{{? ({{getvar::hp}} - 10) * 2}}
```

사칙연산, 거듭제곱(`^`), 나머지(`%`), 비교(`<`, `>`, `<=`, `>=`, `==`, `!=`), 괄호를 쓸 수 있습니다. 비교식은 참이면 `1`, 거짓이면 `0`이 됩니다.

:::caution[물음표 뒤에 공백이 꼭 필요합니다]
`{{?1+2}}`처럼 붙여 쓰면 계산식으로 인식하지 않고 글자 그대로 남습니다. 반드시 `{{? 1+2}}`처럼 띄어 쓰세요.
:::

## 참과 거짓

CBS에서 **참은 `1`과 `true` 두 가지뿐**입니다. `yes`, `2`, `참`, 빈 문자열을 포함해 나머지는 모두 거짓입니다.

그래서 아래 조건은 `hp`가 `7`이어도 거짓입니다. "값이 들어 있는지"를 확인하는 조건이 아닙니다.

```text
{{#when::{{getvar::hp}}}}...{{/when}}
```

[`and`](/cbs/reference/#cbs-and), [`or`](/cbs/reference/#cbs-or), [`not`](/cbs/reference/#cbs-not) 함수는 기준이 더 엄격해서 **`1`만** 참으로 봅니다. 이 함수들에는 `true`도 거짓입니다.

값이 있는지 보려면 비교 연산자를 쓰세요. 없는 변수를 읽으면 빈 문자열이 아니라 `null`이 나오는 점도 기억해 두면 좋습니다.

```text
{{#when::{{getvar::hp}}::isnot::null}}hp가 설정되어 있습니다.{{/when}}
```

## 조건문: `#when`

```text
{{#when::{{getvar::hp}}::<=::0}}
쓰러졌습니다.
{{:else}}
아직 버틸 만합니다.
{{/when}}
```

`{{#when::조건}}`으로 열고 `{{/when}}`으로 닫습니다. 조건이 참이면 `{{:else}}` 앞부분이, 거짓이면 뒷부분이 남습니다.

### 연산자

| 쓰는 법 | 참이 되는 경우 |
| --- | --- |
| `A::and::B` | A와 B가 모두 참 |
| `A::or::B` | A나 B 중 하나라도 참 |
| `not::A` | A가 거짓 |
| `A::is::B` | A와 B가 똑같은 문자열 |
| `A::isnot::B` | A와 B가 다른 문자열 |
| `A::>::B`, `A::<::B`, `A::>=::B`, `A::<=::B` | 숫자로 바꿔 비교한 결과 |
| `var::이름` | 채팅 변수 `이름`의 값이 참 |
| `이름::vis::값` | 채팅 변수 `이름`의 값이 `값`과 같음 |
| `이름::visnot::값` | 채팅 변수 `이름`의 값이 `값`과 다름 |
| `toggle::이름` | 토글 `이름`이 켜져 있음 (전역 변수 `toggle_이름`이 참) |
| `이름::tis::값`, `이름::tisnot::값` | 토글 `이름`의 값이 `값`과 같음 / 다름 |

조건 앞에 붙이는 특별한 단어도 있습니다.

- `keep::조건`: 블록 앞뒤의 빈 줄을 지우지 않습니다.
- `legacy::조건`: 옛 `#if`처럼 처리합니다. 이 모드에서는 `{{:else}}`를 쓸 수 없습니다.

### 연산자는 오른쪽부터 묶입니다

연산자가 여러 개면 **맨 오른쪽부터** 하나씩 계산합니다. 수학의 연산자 우선순위나 왼쪽부터 읽는 순서와 다르니 주의하세요.

```text
{{#when::A::and::B::or::C}}     →  A and (B or C)
{{#when::not::A::and::B}}       →  not (A and B)
```

예를 들어 `{{#when::0::and::0::or::1}}`은 `0 and (0 or 1)`이므로 거짓입니다. 헷갈린다면 [`and`](/cbs/reference/#cbs-and), [`or`](/cbs/reference/#cbs-or), [`not`](/cbs/reference/#cbs-not) 함수로 조건을 미리 계산해 넣으세요.

```text
{{#when::{{or::{{and::{{getvar::a}}::{{getvar::b}}}}::{{getvar::c}}}}}}
(a and b) or c 일 때만 보입니다.
{{/when}}
```

:::caution[모르는 연산자는 조용히 무시됩니다]
`{{#when::A::iss::B}}`처럼 연산자 이름을 잘못 쓰면 오류가 나지 않고, 연산자와 A를 버린 채 **B가 참인지만** 봅니다. 조건이 이상하게 동작하면 연산자 철자를 확인하세요.
:::

### `{{:else}}`와 줄바꿈

- 블록이 **여러 줄**이면 `{{:else}}`는 다른 글자 없이 **한 줄을 혼자** 차지해야 합니다.
- 블록이 **한 줄**이면 `{{#when::1}}예{{:else}}아니오{{/when}}`처럼 어디에 써도 됩니다.
- 여러 줄 블록은 맨 앞과 맨 뒤의 빈 줄을 지웁니다. 각 줄의 앞 공백은 그대로 둡니다. 빈 줄까지 지키려면 `keep`을 쓰세요.

:::danger[거짓인 쪽도 일단 계산됩니다]
`#when`은 조건과 상관없이 블록 안의 CBS를 **모두 계산한 다음** 필요 없는 쪽을 버립니다. 그래서 거짓인 쪽에 있는 `{{setvar}}`도 실행됩니다.

```text
{{#when::0}}{{setvar::hp::0}}{{/when}}
```

이 블록은 아무것도 출력하지 않지만, 채팅 메시지 안에 있다면 `hp`를 `0`으로 바꿉니다. 조건에 따라 변수를 바꾸고 싶다면 다음 방법 가운데 하나를 쓰세요.

- 값 쪽을 조건으로 고릅니다: `{{setvar::hp::{{#when::조건}}0{{:else}}{{getvar::hp}}{{/when}}}}`
- `legacy` 모드를 씁니다. `{{#when::legacy::조건}}`은 거짓일 때 안쪽을 아예 계산하지 않습니다. 대신 `{{:else}}`를 쓸 수 없습니다.
- 트리거 스크립트를 씁니다.
:::

## 반복문: `#each`

```text
{{#each ["사과","배","귤"] as 과일}}
- {{slot::과일}}
{{/each}}
```

배열의 원소마다 블록을 한 번씩 반복하고, `{{slot::이름}}`을 그 원소로 바꿉니다.

- 배열은 JSON 배열(`["a","b"]`)이나 `§`로 구분한 문자열(`a§b`)로 줄 수 있습니다. [`makearray`](/cbs/reference/#cbs-makearray) 같은 함수의 결과를 넣어도 됩니다.
- 블록 안의 CBS는 `slot`을 바꿔 넣은 **다음에** 계산됩니다. 그래서 `{{#each [1,2] as x}}{{? {{slot::x}}*10}}{{/each}}`는 `1020`이 됩니다.
- `slot` 이름은 `as` 뒤에 쓴 이름과 정확히 같아야 합니다.
- 기본적으로 각 줄의 앞 공백과 블록 앞뒤 공백을 지웁니다. 그대로 두려면 `{{#each::keep 배열 as 이름}}`을 씁니다.

## 변수

| 종류 | 읽기 | 쓰기 | 범위 |
| --- | --- | --- | --- |
| 채팅 변수 | `{{getvar::이름}}` | `{{setvar::이름::값}}`, `{{addvar::이름::수}}`, `{{setdefaultvar::이름::값}}` | 지금 채팅방. 채팅과 함께 저장됩니다. |
| 전역 변수 | `{{getglobalvar::이름}}` | (CBS로는 쓸 수 없음) | 모든 채팅과 캐릭터 |
| 임시 변수 | `{{tempvar::이름}}` | `{{settempvar::이름::값}}` | 지금 처리 중인 글 하나 |

없는 채팅 변수를 읽으면 `null`이 나옵니다. 단, 캐릭터나 프롬프트 템플릿에 기본 변수가 설정되어 있으면 그 값이 나옵니다.

### `setvar`는 언제 실행될까

`setvar`, `addvar`, `setdefaultvar`는 **채팅 기록에 저장된 메시지 안에 있을 때만** 실행됩니다. 메시지를 보낼 때와 AI 응답을 받은 뒤에 채팅 메시지 전체를 훑으며 실행하고, 실행이 끝난 CBS는 메시지에서 지워지므로 한 번만 적용됩니다.

그 밖의 곳에서는 실행되지 않습니다.

- 채팅 화면에 표시할 때는 실행하지 않고 숨기기만 합니다.
- 캐릭터 설명, 로어북, 프롬프트 같은 곳에 쓰면 실행되지 않고 글자 그대로 남습니다.

그래서 흔히 정규식 스크립트로 AI 응답에 `{{setvar::...}}`를 끼워 넣어 메시지에 저장되게 하는 방식을 씁니다. 더 복잡한 처리가 필요하면 트리거 스크립트를 쓰세요.

## 글자 그대로 보여 주기

CBS 문법 자체를 화면에 보여 주고 싶을 때 쓰는 방법들입니다.

| 쓰는 법 | 동작 |
| --- | --- |
| `{{#puredisplay}}...{{/puredisplay}}` | 안의 CBS를 계산하지 않고 그대로 보여 줍니다. |
| `{{#escape}}...{{/escape}}` | 안의 `{`, `}`, `(`, `)`를 특수 문자로 바꿔 두어 이후 처리에서 CBS로 읽히지 않게 하고, 화면에 그리거나 AI에게 보낼 때 원래 글자로 되돌립니다. 공백을 지키려면 `{{#escape::keep}}`을 씁니다. |
| `{{bo}}`, `{{bc}}` | 각각 `{{`, `}}`처럼 보이는 특수 문자를 넣습니다. |

`#pure`는 더 이상 권장되지 않으며 `#puredisplay`로 대체되었습니다.

## 주석

| 쓰는 법 | AI에게 보내는 프롬프트 | 채팅 화면 |
| --- | --- | --- |
| `{{comment::내용}}` | 지워짐 | 주석 상자로 보임 |
| `{{// 내용}}` | 아래 참고 | 아래 참고 |

:::caution[`{{// ...}}`는 생각처럼 지워지지 않습니다]
CBS 레퍼런스에는 `{{// ...}}`가 주석이라고 적혀 있지만, 이 페이지가 확인한 버전의 소스 코드에서 이를 지우는 곳은 **로어북 키워드 검사**뿐이었습니다. CBS 파서를 거친 뒤에도 글자 그대로 남습니다. 프롬프트와 화면 양쪽에서 확실히 숨기려면 아래처럼 감싸는 방법이 있습니다. `legacy` 모드의 거짓 블록은 안쪽 CBS를 계산하지도 않습니다.

```text
{{#when::legacy::0}}
여기는 어디에도 나오지 않습니다.
{{/when}}
```
:::

## 더 이상 권장되지 않는 문법

- `{{#if 조건}}...{{/if}}`, `{{#if_pure 조건}}...{{/if_pure}}`: 연산자를 붙일 수 없어 `#when`으로 대체되었습니다. `#if_pure`는 `{{#when::keep::조건}}`과 같습니다.
- `{{#pure}}`: `{{#puredisplay}}`로 대체되었습니다.

## 레퍼런스에 없는 문법

파서에는 레퍼런스에 실리지 않은 블록이 몇 개 더 있습니다. 공식 설명이 없어 동작이 바뀔 수 있으니 참고만 하세요.

- `{{#func 이름 ...}}...{{/func}}`와 `{{call::이름::인자}}`: 블록을 함수처럼 정의하고 불러 씁니다. 블록 안에서 `{{arg::0}}`은 함수 이름, `{{arg::1}}`부터가 인자입니다.
- `{{#code}}...{{/code}}`: 줄바꿈과 탭을 지우고 `\n`, `\t`, `\uXXXX` 같은 이스케이프를 실제 문자로 바꿉니다.
